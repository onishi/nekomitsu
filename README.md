# ねこみつ — 猫は液体

「猫は液体（Cats are liquid）」を、そのままゲームにしたブラウザゲームです。

画面中央の大きな金魚鉢へ、上から猫を1匹ずつ落とします。猫は柔らかい soft-body で、
ぽすっ → ぐにゃっ → むにゅ〜 → すぽっ と形を変えながら隙間へ収まり、
落ち着くと目を閉じて眠ります。金魚鉢が猫でいっぱい（充填率 100% 超え = 口からはみ出すくらい）になるとステージクリアです。

攻略より「もう1匹落としたくなる触感」を優先しています。ゲームオーバーはありません。

## しくみ

### 物理（`src/physics/`）

Matter.js などの剛体ライブラリも検討しましたが、「本来の形に戻ろうとする柔らかい体」と
「体積を保ったまま隙間へ流れ込む」挙動を安定して出すには、剛体＋バネの組み合わせより
位置ベースの soft-body の方が向いているため、小さな専用ソルバを書いています（依存ライブラリなし）。

- **小ステップ XPBD**（1フレーム4サブステップ）: 距離制約・面積制約
- **面積保存**: 胴体の面積をほぼ一定に保つ。押されると横へ広がり、隙間へ流れ込む ＝ 液体っぽさの源
- **シェイプマッチング**（Müller 2005）: 外力がなければ「香箱座りの猫の形」へ戻る力。
  胴体は affine 変形（β）を許し、面積を保ったまま潰れる・伸びる squash & stretch をする
- **衝突**: 粒子 vs 他の猫の輪郭ポリゴン（辺を厚みのあるカプセルとして扱う）、粒子 vs 金魚鉢の曲面。
  ガラスは摩擦を小さく、毛並み同士は少し大きく
- 空間グリッドで近傍の辺だけを調べる。18匹（約730粒子）で物理は 1フレーム 3ms 前後

### 猫（`src/cat/`）

猫1匹は約40個の粒子でできています。

| 部位 | 構成 | 硬さ |
| --- | --- | --- |
| 胴体・腹 | 輪郭リング（14〜24粒子）+ 面積保存。前半身・後半身の2クラスタを腰の関節でつなぐ | とても柔らかい。腰で ±75° まで曲がり、落ち着くほどさらに柔らかくなる |
| 頭 | 輪郭リング + 中心、独立したクラスタ | ほぼ剛体。顔は潰れない |
| 足 | 胴体クラスタにぶら下がる粒子 | 中くらい。落下中はぶらーん、着地したらたたむ |
| 尻尾 | 6〜7節のチェーン + 曲げ制約 | とても柔らかい。起きているときは立て、眠ると体に巻き付ける |

ふるまい（`cat.ts`）:

- 着地の瞬間だけ体を柔らかくして大きく潰れ、反動で少し戻る。跳ねすぎないよう着地直後の上向き運動は吸収
- 落ち着いてくると「居心地補助」が働く: 何にも触れていない輪郭をほんの少し外へ膨らませる
  （面積は保存されるので、結果として体が空いている隙間へ流れ込む）、頭と体をゆっくり起こす、尻尾をしまう
- いずれも力やシェイプマッチングのゴールを少し変えるだけで、テレポートはしない

アクション: 落ち着いた猫は自分から動きます。頭の向きと前足のポーズの目標を少し変えるだけで、動き自体は soft-body に任せています。

- 毛繕い: 前足を口元へ上げて、肉球をペロペロ
- 隣の猫を舐める: 頭のそばにいる猫の方へ頭を寄せて舌を出す。舐められた猫は気持ちよさそうに目を閉じ、ハートが出る
- あくび: 顔を上げて、ふわぁ…と口を大きく開ける
- 寝る: 尻尾を巻いてすやすや（Zz・呼吸）。ときどき起きて毛繕いする

表情: 吊るされている（きょとん）→ 落下中（驚き）→ 着地（びっくり）→ 普通 → 眠そう → 寝る。
押されると目を細め、顔が隣の猫に埋まると気持ちよさそうに目を閉じて頬が赤くなります。

体型（`catTypes.ts`）: ふつうの猫 / ほそい猫 / ながい猫（よく伸びる）/ まる猫（重い）/ 子猫（小さい）/ ふわふわ猫（押されると縮む）。
さらに1匹ごとに太さをランダムに変えています（細めに偏らせ、太い猫ばかりにならないようにしている）。
毛色: キジトラ / 茶トラ / 黒猫 / 白猫 / 三毛 / ハチワレ / サバトラ。`COATS` に追加するだけで増やせます。

### 描画（`src/render/`）

Canvas 2D。物理と描画は分離していて、描画側で

- 粒子位置をシェイプマッチングのゴール形状へ少し寄せる
- 平滑化してから粒子半径ぶん外へ膨らませ、スプラインで輪郭を引く

ことで「中身が多少ぐちゃっとしても見た目は猫らしい輪郭」に補正しています。
胴体全体を楕円に引き伸ばす変形は控えめにし、形に戻る力を弱くしているので、
隣の猫やガラスに沿って部分的にへこんだり膨らんだりする「グニャッ」とした変形が主体になります。
模様（縞・三毛の斑・お腹）は輪郭粒子に張り付けて描くので、体の変形に追従します。
顔・耳は頭クラスタの剛体フレームで描くので、体がどれだけ潰れても崩れません。
ガラスに押し付けられた部分は毛が平たく明るくなり、足がガラスに触れると肉球が見えます。

### 充填率とクリア（`src/game.ts`）

充填率 = 猫が占める面積 ÷ 金魚鉢の容量（口まで）。口より上にはみ出した猫も数え、猫どうしの隙間は数えません。
そのため 100% を超えるには、口からはみ出すくらいまで詰める必要があります（はみ出してOK）。
100% を超えてもすぐにはクリアにせず、物理が落ち着くのを待って再判定します（隙間へ流れ込んで下がったら続行）。
クリアすると全員でむにゅっと押し合って収まり、満足そうに目を閉じます。

### サウンド（`src/audio.ts`）

WebAudio で合成しているので音声ファイルは不要です。落とすときにニャー（体の小さい猫ほど高い声）/ ぽすっ（着地）/ むにゅ（押し込み）/ すぽっ（隙間に収まる）/
ゴロゴロ（眠る）/ クリア音。最初の操作で有効になり、音がなくてもゲームは成立します。
