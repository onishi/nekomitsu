# ねこみつ — 猫は液体

「猫は液体（Cats are liquid）」を、そのままゲームにしたブラウザゲームです。

画面中央の大きな金魚鉢へ、上から猫を1匹ずつ落とします。猫は柔らかい soft-body で、
ぽすっ → ぐにゃっ → むにゅ〜 → すぽっ と形を変えながら隙間へ収まり、
落ち着くと目を閉じて眠ります。金魚鉢が猫でいっぱい（口から少し盛り上がるくらい）になるとステージクリアです。

攻略より「もう1匹落としたくなる触感」を優先しています。ゲームオーバーはありません。

## ねこけし（もうひとつのモード）

開始時のメニュー（またはタイトルを押したメニュー）で「ねこみつ」と「ねこけし」を選べます。

「ねこけし」は、猫を合体させて消し、金魚鉢がいっぱいにならないようにするゲームです。

- だんだん難しくなります。最初は4種類（茶トラ・キジトラ・黒・白）で、落とした数に応じて
  ハチワレ（16匹目）→ サバトラ（36匹目）→ 三毛（60匹目）と種類が増えます（「あたらしい猫」と表示）。
  80匹目からは4匹ぶんの大きさにならないと消えなくなり（「むずかしくなった！」と表示）、
  120匹目からは上限ラインを超えていられる時間が3秒から最短1.8秒まで縮みます。
  さらに後半は、見間違えにくい新しい柄が加わります: 牛柄（100匹目）→ 茶白（150匹目）。
- 同じ色・柄の猫どうしが少しの間くっつくと、むにゅっと融合して
  2匹ぶんの大きさの1匹になります。融合した猫は、さらに同じ猫と融合できます。
- 3匹ぶん以上の大きさになると、ぽんっと毛玉がはじけて消えます。空いた場所へ周りの猫が落ちて、また融合・消滅…と連鎖します。
- 金魚鉢の口（点線）を猫が3秒（終盤は短くなる）超えたままだとゲームオーバー。一瞬はみ出すだけなら大丈夫で、超えている間は線が赤く点滅します。
- 得点: 融合は 10×大きさ（連鎖中は倍率つき）、消滅は 100×大きさ×2^(連鎖数−1)。ハイスコアはブラウザに保存し、プレイ中に画面下へ表示します（更新中は色が変わる）。

融合は画像の切り替えではなく soft-body で行います（`src/keshi.ts`）。
接触した2匹の当たり判定を切って引き寄せ合い、体が重なったところで2匹ぶんの大きさの猫1匹に置き換えます。
融合中は2匹の輪郭を先に描いてから中身を重ねるので、重なった境目が消えて1つのかたまりに見えます。
置き換えた瞬間の猫は2匹を合わせた横長の形で、そこからむにゅっと本来の猫の形に戻ります。
ねこみつの挙動やバランスはそのままです。

## 遊び方

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 左右に動かす | マウス移動 / ← → | 指を左右に動かす |
| 落とす | クリック（どこでも）/ Space。容器の外をドラッグして狙ってから離しても落ちる | タップ（どこでも。指を離した位置に落ちる）。容器の外をドラッグして狙ってから離しても落ちる |
| かき混ぜる | 容器の中でドラッグ（または長押し） | 容器の中でなぞる（または長押し） |
| ゲームの切り替え・最初からやり直す | タイトル（ねこみつ / ねこけし）→ メニュー | タイトル → メニュー |
| オートモード（鑑賞用） | 右上の ▶（もう一度押すと ■ で停止） | 右上の ▶（もう一度押すと ■ で停止） |

オートモード中は、適当な位置へ猫を動かして落とし、クリアしたら少し余韻を見せて次の面へ進みます。
判定中は落とさずに待ちます。オート中もタップやかき混ぜはそのまま使えます。

容器の中で押したまま動かす（または0.3秒長押しして輪が一周する）とかき混ぜが始まり、指が丸い物体として猫を押しのけ、なぞった方向へ猫を引きずります（`Game.applyStir`）。
触られた猫は目を細め、寝ていても起きます。

## しくみ

### 物理（`src/physics/`）

Matter.js などの剛体ライブラリも検討しましたが、「本来の形に戻ろうとする柔らかい体」と
「体積を保ったまま隙間へ流れ込む」挙動を安定して出すには、剛体＋バネの組み合わせより
位置ベースの soft-body の方が向いているため、小さな専用ソルバを書いています（依存ライブラリなし）。

- **小ステップ XPBD**（1フレーム4サブステップ）: 距離制約・面積制約
- **面積保存**: 胴体の面積をほぼ一定に保つ。押されると横へ広がり、隙間へ流れ込む ＝ 液体っぽさの源
- **シェイプマッチング**（Müller 2005）: 外力がなければ「香箱座りの猫の形」へ戻る力。
  胴体は affine 変形（β）を許し、面積を保ったまま潰れる・伸びる squash & stretch をする
- **衝突**: 粒子 vs 他の猫の輪郭ポリゴン（辺を厚みのあるカプセルとして扱う）、粒子 vs 金魚鉢の曲面。
  ガラスは摩擦を小さく、毛並み同士は少し大きく
- 空間グリッドで近傍の辺だけを調べる。18匹（約730粒子）で物理は 1フレーム 3ms 前後

### 容器（`src/physics/container.ts`, `shapes.ts`）

ステージごとに大きさと形が変わります。1面は金魚鉢、そのあとは
ビーカー → 三角フラスコ → どんぶり → 六角形 → 丸底フラスコ → 砂時計 → ひし形 → 花瓶 →
S字 → クランク → 螺旋（現実にはない、曲がりくねった管）の順で、13面目以降は全部の形からランダム。
容量はステージが進むにつれて大きくなります。

管の形（S字・クランク・螺旋）は中心線に沿って一定の太さの管を作ります。太さは容量ではなく
「猫1匹が通り抜けられる太さ」で決めていて、横に進む区間にも傾きをつけて猫が流れ下るようにしています。

形は「口の左端 → 底 → 口の右端」の内壁の折れ線で表し、物理（粒子を内側へ押し戻す）と描画（ガラス・反射・口の縁）で共通に使います。
壁から十分離れた内側の粒子は判定を省略するグリッドを持っているので、形が複雑でも軽いです。
フラスコの首や砂時計のくびれは猫より細く、猫が液体のように形を変えて通り抜けます。

### 猫（`src/cat/`）

猫1匹は約40個の粒子でできています。

| 部位 | 構成 | 硬さ |
| --- | --- | --- |
| 胴体・腹 | 輪郭リング（14〜24粒子）+ 面積保存。前半身・後半身の2クラスタを腰の関節でつなぐ | とても柔らかい。腰で ±75° まで曲がり、落ち着くほどさらに柔らかくなる |
| 頭 | 輪郭リング + 中心、独立したクラスタ | ほぼ剛体。顔は潰れない |
| 足 | 胴体クラスタにぶら下がる粒子 | 中くらい。落下中はぶらーん、着地したらたたむ |
| 尻尾 | 6〜7節のチェーン + 曲げ制約 | とても柔らかい。起きているときは立て、眠ると体に巻き付ける |

ふるまい（`cat.ts`）:

- 着地の瞬間だけ体を柔らかくして大きく潰れ、反動で少し戻る。跳ねすぎないよう着地直後の上向き運動は吸収
- 落ち着いてくると「居心地補助」が働く: 何にも触れていない輪郭をほんの少し外へ膨らませる
  （面積は保存されるので、結果として体が空いている隙間へ流れ込む）、頭と体をゆっくり起こす、尻尾をしまう
- いずれも力やシェイプマッチングのゴールを少し変えるだけで、テレポートはしない

アクション: 落ち着いた猫は自分から動きます。頭の向きと前足のポーズの目標を少し変えるだけで、動き自体は soft-body に任せています。

- 毛繕い: 前足を口元へ上げて、肉球をペロペロ
- 隣の猫を舐める: 頭のそばにいる猫の方へ頭を寄せて舌を出す。舐められた猫は気持ちよさそうに目を閉じ、ハートが出る
- あくび: 顔を上げて、ふわぁ…と口を大きく開ける
- 寝る: 尻尾を巻いてすやすや（Zz・呼吸）。ときどき起きて毛繕いする

不機嫌な猫: 約12%の猫は少し不機嫌です。ふだんはジト目で口が「へ」の字、触られたり押されたり舐められたりすると
耳を横に倒して（イカ耳）目頭を下げ、かき混ぜると「ウゥ…」と低くうなります。他の猫は舐めず、なかなか寝つきません。

表情: 吊るされている（きょとん）→ 落下中（驚き）→ 着地（びっくり）→ 普通 → 眠そう → 寝る。
押されると目を細め、顔が隣の猫に埋まると気持ちよさそうに目を閉じて頬が赤くなります。

体型（`catTypes.ts`）: ふつうの猫 / ほそい猫 / ながい猫（よく伸びる）/ まる猫（重い）/ 子猫（小さい）/ ふわふわ猫（押されると縮む）。
さらに1匹ごとに太さをランダムに変えています（細めに偏らせ、太い猫ばかりにならないようにしている）。
まる猫・ふわふわ猫はレアで、太めの猫（高さが幅の0.6倍以上）は全体の4%ほどです。
胴体の輪郭は楕円ではなく、お尻（腰）が高く、首へ向かってなだらかに細くなり、後ろ脚の前のお腹が少しくびれた形です（`bodyProfile`）。
形を整えても面積は変えないので、猫1匹ぶんの量は同じです。
毛色（14種類）: キジトラ / 茶トラ / 黒猫 / 白猫 / 三毛 / ハチワレ / サバトラ / キジ白 / 茶白 / サバ白 / 牛柄 / くつした / グレー / クリーム。
「〇〇白」は口元・あご・胸・お腹・足先が白（`bicolor`）、くつしたは黒猫のすねから下が白（`socks`）。`COATS` に追加するだけで増やせます。

### 描画（`src/render/`）

Canvas 2D。物理と描画は分離していて、描画側で

- 粒子位置をシェイプマッチングのゴール形状へ少し寄せる
- 平滑化してから粒子半径ぶん外へ膨らませ、スプラインで輪郭を引く

ことで「中身が多少ぐちゃっとしても見た目は猫らしい輪郭」に補正しています。
胴体全体を楕円に引き伸ばす変形は控えめにし、形に戻る力を弱くしているので、
隣の猫やガラスに沿って部分的にへこんだり膨らんだりする「グニャッ」とした変形が主体になります。
模様（縞・三毛の斑・お腹）は輪郭粒子に張り付けて描くので、体の変形に追従します。
顔・耳は頭クラスタの剛体フレームで描くので、体がどれだけ潰れても崩れません。
ガラスに押し付けられた部分は毛が平たく明るくなり、足がガラスに触れると肉球が見えます。
脚は肩・腰（胴体の輪郭に固定した付け根）から肉球の粒子まで、関節で曲がる先細りの形を2関節の IK で描きます。
胴体より先に描くので付け根は隠れ、輪郭からはみ出た部分だけが見えます（転がっても背中側に手が出ない）。
吊るしている間は脚が重力の向きにだらんと垂れ、動かすと振り子のように遅れて揺れます（`Cat.legSwing`）。
毛繕いでは手先を口元へ寄せます。

### 充填率とクリア（`src/game.ts`, `src/physics/shapes.ts` の `FILL_GOALS`）

充填率 = 猫が占める面積 ÷ 容器の容量（口まで）。口より上にはみ出した猫も数え、猫どうしの隙間は数えません。
隙間の割合は形によって違うので、クリア条件は形ごとに決めています。1匹ずつ落として山が落ち着くのを待つ
シミュレーションで「山のてっぺんが口の上 45px（猫の半分くらい）に届いたときの充填率」を形ごとに測り、
その少し手前（80〜97%）をクリア条件にしました。どの形でも、口から少し盛り上がるくらいでクリアになります。
条件を超えてもすぐにはクリアにせず、物理が落ち着くのを待って再判定します（隙間へ流れ込んで下がったら続行）。
一度表示した（吊るした）猫は消えず、判定中やクリア後でも必ず落とせます。落とさずに次のステージへ進んだ場合も同じ猫を持ち越します。
クリアすると全員でむにゅっと押し合って収まり、満足そうに目を閉じます。

### サウンド（`src/audio.ts`）

落とすときのニャーは録音素材（`public/sounds/meow-01〜05.mp3`、下記クレジット）からランダムに選び、頭の無音を飛ばして音量をそろえ、
体の大きい猫ほど再生を遅くして低い声にします。読み込めなかったときは合成のニャー（`src/meow.ts`: 声帯っぽい音源に揺らぎと息の音を足し、口の「ミ→ア→ウ」の動きを3つのフォルマントで合成）に切り替わります。
そのほかの効果音は WebAudio で合成しています: ぽすっ（着地）/ むにゅ（押し込み）/ すぽっ（隙間に収まる）/
ゴロゴロ（眠る）/ クリア音。最初の操作で有効になり、音がなくてもゲームは成立します。

## ねこ図鑑（隠しページ）

`/zukan.html` に、柄14種類と体型6種類を並べた図鑑があります。メニュー（タイトルをタップ）の右下にうっすら見える肉球が隠しリンクです。
ゲームと同じ描画で吊るした猫を表示し、タップすると鳴きます。ねこけしで何匹目から出てくる柄かも書いてあります。
動作確認用に、ゲームの URL に `?coat=ushi` や `?cat=long` を付けると、落とす猫の柄や体型を固定できます。
